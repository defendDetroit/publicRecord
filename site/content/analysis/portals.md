## Why These Don't Rot

Regular QR codes point to someone else's redirect service. When the subscription expires, the QR code goes nowhere — or worse, goes somewhere WRONG. That violates entropy. That's a sticky link rotting in the wild.

These portals point to infrastructure we control:

| If this fails... | This catches it | Because |
|---|---|---|
| detroit.primals.eco | GitHub Pages mirror | Auto-built on every push |
| GitHub Pages | git.primals.eco | Forgejo is self-hosted |
| Both sites | git clone (local copy) | 1,242 people have clones |
| URL path changes | Night box (welcome mat) | Every 404 redirects to help |
| Server goes down | The data is on YOUR disk | The clone IS the backup |

The BingoCube portal isn't a link. It's a keystone. It opens a door to content that heals itself. The membrane is the only QR code system where every endpoint is self-hosting, self-healing, and self-replicating.
