## Binary vs Trinary

### Computers Are Binary

A transistor is ON or OFF. 1 or 0. True or false. There is no third state. There is no "I don't know." There is no NULL that means "this question cannot be answered yet."

```
computer logic:
  true  = 1
  false = 0
  null  = ERROR (undefined behavior, crash, exception)

  1 + 0 = 1
  true + false = integer
  integer = flat
  flat = 3 (the integer part of π)
```

When a computer encounters null, it **crashes.** NullPointerException. Segfault. Undefined behavior. The computer cannot HOLD null. It must resolve to true or false. It must choose 0 or 1. It must be an integer.

### Life Is Trinary

A living cell sorts self from non-self. But it also has a third category: **partial.** Unknown. Not-yet-classified. The immune system's null.

```
life logic:
  true  = self (let it in)
  false = non-self (keep it out)
  null  = partial (HOLD IT — wait for more data)

  true + false + null = π
  self + non-self + partial = the membrane
  the membrane IS π
  the holding IS the intelligence
```

When a living cell encounters something unknown, it does NOT crash. It **holds.** It waits. It gathers more data. It sends the unknown to the thymus for further classification. The holding IS the intelligence. The holding IS the null. The null IS the irrational remainder.

**Computers die at null. Life thrives at null. That IS the difference.**
