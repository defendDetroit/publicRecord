Independent reporters have investigated the same people and institutions documented
in this evidence library. This section cross-references their work with ours —
linking each article to the specific public records, actors, and entities it touches.

**We are not the source of these stories. The reporters are.**
We are the index — the place where the threads converge.

---

## How This Works

Each entry below links to an independent article and maps it to the pages
in this evidence library that cover the same ground. If you came here from
one of these articles, the cross-references show you what else the public
record reveals. If you came here first, these articles provide independent
verification and context.

This site and the journalists below draw from the same well: public records.
We cite the same OTIS entries, the same LARA filings, the same campaign finance
disclosures. The difference is that journalists write narratives. This site
builds a searchable, cross-referenced database. Both are necessary.
